# UI sounds

`marines_ui_part_fitted.wav` plays when a part lands on a doll point in the mech lab or on the
boat deck (`UiSounds.partFitted`).

It is the owner's take "Dillons-Refried-beans", rendered from an ElevenLabs "heavy steel vault
door" effect on the Mechlab Drop Sound page (https://claude.ai/artifact/A2Dq7xyu3oGYnZSCYYsUD8),
which holds the source sound and the chain, so a new take starts there.
