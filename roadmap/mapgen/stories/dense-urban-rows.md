# Dense urban row blocks

## Goal

Make large `DENSE_BLOCK` lots fight like intentional close-quarters urban
spaces rather than four tiny generic shells. Preserve the compact legacy fill
for small lots, but give qualifying lots readable mixed-use row buildings,
shared alleys, room purposes, and controlled cover.

## Scope

- Qualifying 13x10+ dense lots become two elongated buildings flanking a
  three-cell service alley. Staggered one-cell cover pockets must always leave
  a two-cell clear infantry lane, sized around marine radius.
- One row is a tenement with a common room and bedroom; the other is an alley
  market with a shop floor and stockroom. Each row gets a guaranteed interior
  partition and direct alley-facing entrance plus an opposed escape/service
  door.
- Purpose-aware fixtures reuse existing two-cell beds/sofas, shelves, crates,
  and counters without splitting a room or blocking doorway clearance.
- Selective bedroom and shop-floor facade windows reuse the non-traversable,
  shoot-through structural cover seam.
- Lots below the tactical threshold retain the established four-shell compact
  pattern so dense-block frequency does not collapse.

## Acceptance

- Direct tests cover both alley orientations, room purposes, alley-facing and
  opposed entrances, remaining two-cell passage width, purpose fixtures,
  window firing lanes, deterministic output, and compact fallback behavior.
- Representative cities contain tactical dense rows without losing global
  connectivity.
- A dedicated rendered preview passes visual review, and the map validation
  scan plus full suite remain green.

## Out of scope

- Fusing either row across adjacent BSP leaves.
- New art; the slice establishes the mixed-use urban grammar with the current
  residential, shop, and exterior-cover vocabulary.
