# Fire-stance normalization

Status: PARKED

Written: 2026-08-23

Read `ecs-nouns.md` before reviving this story.

## Activation gate

A playtest identifies a concrete mismatch in moving, settling, or dwelling fire
posture rather than a storage/extraction defect.

## Goal

Normalize the intended stance for a combatant that is moving, settling, or
dwelling before it emits a fire intent. This is a deliberate behavior change,
not unfinished `FiringSystem` extraction.

## Acceptance

- Every firing posture has one documented moving/stanced rule.
- Behavior authors intent; `FiringSystem` remains the sole execution owner.
- Focused tests cover each changed posture and a live playtest confirms cadence/feel.
