# Campaign documentation

Start with `campaign-overview.md` for the campaign's authored route, arc status,
capability progression, and documentation map.

Each authored arc has its own folder under `arcs/`, containing an enduring
overview in `design/`, an open-work board, and its remaining implementation or
acceptance plans in `stories/`. Shared campaign systems keep their existing
domain folders and canonical noun documents.

For campaign-wide rules read `campaign-nouns.md`; for the long-term progression
model read `meta-progression.md`.
