# Narrative live acceptance

Status: READY

Written: 2026-08-23

## Outcome

Validate the shipped comms-officer briefing context in a running campaign.

## Acceptance

- A returning patron reads direct shared history; a relevant confirmed Chronicle
  fact outranks a local echo; a first-time patron can receive only one bounded
  local echo.
- Target-aware variants name a resolvable past location naturally, while
  missing or legacy targets stay neutral.
- The officer reports measured events without exposing internal ids, hidden
  moral values, inferred motives, or changing campaign state.
- Reloading and reopening preserve the same factual context without duplicate
  memory or Chronicle facts.

## Scope

This is manual presentation acceptance only. Do not add new memory sources,
archetypes, relationship inference, or UI in this story.
