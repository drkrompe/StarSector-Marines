# v0.1 alpha playtest script

Status: ACTIVE — the owner's ordered live-acceptance pass for the v0.1 gates in `v0.1-alpha.md`.
Written: 2026-10-21

One script, three runs. Each step says what to do, the one-line pass test, and the
story it closes. **Pass** ticks the story's live-acceptance line. **Fail** writes one
line under "Notes" at the bottom (step id, what you saw) and play on; don't stop to fix.

Tags: **[R]** release-blocking (a fail blocks the alpha), **[N]** nice-to-have (a fail
ships as a known issue). Do the [R] steps and skip the [N] ones and you can still ship.

Total: about 5.5 h of play if everything is done; **about 4.5 h for the 31 [R] steps**
(11 [N] more). The core without supply route and Nexerelin (blocks A–D and F) is 21 [R] steps, about 3.5 h.

## Setup

- Build: use the sibling release-build's jar, deployed with `deployMod`. Source
  `DevConfig` ships `DEBUG_CLIENT`, `CAMPAIGN_DEBUG_INTEL` and `DEBUG_UI_WORKBENCH` as
  `true` (compile-time). A build with them on shows a "DEBUG — All Missions" client at every
  planet and a debug button on HQ. **Don't use them in Runs 1–2**; they hide the real
  discovery path. If the release build still has them on, just ignore the debug client.
  Step S1 checks which build you have.
- Game: Starsector 0.98a-RC8, Corvus sector, 1920x1080, UI scale 100%. Normal difficulty.
  No Nexerelin in Runs 1–2 (disable it in the launcher).
- Money: the story gives ~473 spendable credits, then Relief pays 6,000 and Counterattack
  9,000. The restoration orders below are sequenced to fit that. If a step is short on
  credits, skip that order and note it. Don't cheat money unless a step says so, because
  affordability is part of the check (`first-mission-preparation.md`, `boat-condition-and-repairs.md`).
- Saves: name each save as written. Keep all of them until the script is done.
  Starsector's own Save command at a safe spot (docked, no dialog) is fine.

| Save | Taken | Used by |
|---|---|---|
| `S0-start` | first frame after the prologue | Run 3 restart if needed |
| `S1-docked` | docked at the start port, before paying | A2 refusals, A3 leave/reload |

## What this script cannot close

These tracker rows need decisions or builds, not playtest, and are out of this script:
scope/lance caps, localization (`alpha-localization.md`), the installable build, vehicle/mech
lance lifecycle, tier rewards. Officer careers and personnel need their own pass
(`personnel-live-acceptance.md`, `officer-careers.md`); while playing, note anything odd
about dossiers or specialties under "Notes".
